Chaque coup de tes parties est comparé à tes répertoires. Sortir du répertoire n'est pas une faute : une erreur, c'est un coup hors répertoire et mauvais. Les deux sont listés ici, séparément.

Entraînement

Quatre chantiers : tes erreurs d'ouverture, tes gaffes en jeu, tes répertoires et les quiz des leçons.

1 · Erreurs d'ouverture

0

Les coups qui sortaient de ton répertoire et qui étaient mauvais. Sortir du livre n'est pas une faute : ceux-là en sont une. Une position quitte la liste quand tu l'as retrouvée cinq fois de suite sans faute ni indice.

2 · Gaffes en jeu

0

Les positions où tu étais devant, ou perdant de peu, et où tu as laissé filer au moins trois points. Retrouve le coup que tu n'as pas joué ; cinq fois de suite sans faute ni indice, et la position quitte la liste.

3 · Entraîner les ouvertures

0

Tes répertoires, en entier ou seulement ce qui est dû, et les positions que tu as ratées. À chaque position, tu dois retrouver tous tes coups ; l'adversaire joue ses réponses préparées. Le menu « Réviser » limite la révision à tes premiers coups (par exemple jusqu'à ton 3e coup).

4 · Quiz d'ouverture

0

Les quiz des leçons : la position se rejoue depuis le début, puis tu trouves tes coups. Une erreur affiche l'explication de la leçon. Un quiz réussi revient plus tard ; un quiz raté revient demain.

Synchronisation GitHub

Tes appareils (ordinateur, téléphone) se retrouvent dans un dépôt GitHub privé : à l'ouverture, quelques secondes après chaque modification et quand l'app passe en arrière-plan. Chaque envoi garde une version : GitHub conserve tout l'historique.

Créer le dépôt et le jeton (une seule fois)
  1. Sur GitHub, crée un dépôt : nom entraineur-donnees, coche Private, puis Create repository.
  2. Crée un jeton (Fine-grained token) : Repository access → Only select repositories → ton dépôt ; Permissions → Contents → Read and write ; expiration : la plus longue proposée. Quand il expire, l'indicateur passe en erreur : il suffit d'en coller un nouveau ici.
  3. Copie le jeton (il commence par github_pat_), colle-le ci-dessus avec le nom du dépôt, puis Enregistrer et synchroniser.
  4. Fais la même chose sur ton autre appareil, avec le même dépôt et le même jeton.

Le jeton reste sur chaque appareil : il n'est jamais envoyé dans le dépôt. Un dépôt public est refusé, parce que tes parties et ton jeton Lichess y seraient visibles de tous.
